# GlobMeet 页面维度需求文档

**版本：** T1/T2 补充草案  
**定位：** 国际会议预约与参会协同平台  
**本文件作用：** 用页面和用户任务表达需求；不取代 [requirements.md](requirements.md) 中的规则编号与验收标准。

## 1. 产品定位与功能闭环

GlobMeet 面向跨国家和地区的参会人员与会务人员，解决会议发现、预约决策、会务审核、日程同步、变更处理和现场核验之间的信息断裂。产品不提供实时音视频能力；它负责让“可以参加、已被确认、已发生变更、可以入场”这些状态清晰、一致且可追溯。

```text
会议可见
  -> 参会人理解本地时间并申请
  -> 冲突透明、可选择继续或调整
  -> 会务审核
  -> 预约、日程、通知、凭证同步
  -> 会议变更再次同步并提示影响
  -> 现场核验与签到记录
```

## 2. 信息架构

### 2.1 参会人员端

```text
会议（一级）
├─ 会议列表
├─ 筛选与搜索
└─ 会议详情
   └─ 预约申请 / 冲突说明 / AI 替代建议

日程（一级）
├─ 本地时区日程
├─ 日期/视图切换
├─ 冲突标记
└─ AI 行程建议

通知（一级）
├─ 审核结果
├─ 会议变更
└─ 待确认调整

我的（一级）
├─ 我的预约（按状态）
├─ 预约详情与取消
├─ 有效凭证
└─ 偏好设置（语言、时区、演示角色）
```

### 2.2 会务人员端

```text
待办（一级工作区）
├─ 待审申请队列
└─ 申请详情 / 审核决定

会议（一级工作区）
├─ 负责会议列表
└─ 会议变更 / 影响预览

核验（一级工作区）
├─ 选择负责会议
└─ 凭证核验 / 签到结果

个人菜单（非一级）
├─ 当前角色与负责范围
└─ 操作记录入口
```

## 3. 页面需求清单

| 页面 ID | 页面与层级 | 目标用户 | 用户目标 | 必须呈现的信息 | 关键动作 | 进入/离开规则 |
| --- | --- | --- | --- | --- | --- | --- |
| P-01 | 会议列表 / 一级 | 参会人员 | 找到可参加的会议 | 本地时间、会议主题、形式、地点/线上、状态、容量摘要 | 筛选、搜索、查看详情 | 从底部“会议”进入；进入 P-02 |
| P-02 | 会议详情 / 二级 | 参会人员 | 判断是否申请 | 绝对时刻对应的本地时间与原时区、完整说明、议程、容量、预约条件 | 发起预约 | 从 P-01 或日程时间块进入；进入 P-03/P-04 |
| P-03 | 预约确认 / 二级 | 参会人员 | 确认自己的申请意图 | 会议摘要、申请规则、提交后状态 | 提交、返回 | 无冲突时进入 P-05；取消不写入 |
| P-04 | 冲突与建议 / 二级状态页 | 参会人员 | 理解冲突后果并选择下一步 | 冲突会议、重叠时段、影响、AI 替代理由 | 取消、继续提交、采纳/忽略建议 | 仅由 P-03 触发；不自动改已确认日程 |
| P-05 | 申请结果 / 二级状态页 | 参会人员 | 确认申请已送达 | 申请编号、待审核状态、下一步说明 | 查看我的预约、返回会议 | 写入待审申请、记录和通知对象后进入 P-09 |
| P-06 | 日程 / 一级 | 参会人员 | 按本人时区管理已确认/待确认安排 | 日期、所选时区、时间线、状态、冲突标记、会议入口 | 切换日期/时区、查看建议、打开详情 | 从底部“日程”进入；进入 P-02/P-07/P-08 |
| P-07 | AI 行程建议 / 日程内二级 | 参会人员 | 获得可解释的替代安排 | 建议会议/时段、理由、冲突说明、采纳后的影响 | 采纳、修改、忽略 | 仅在日程或冲突中进入；只有采纳改变草稿 |
| P-08 | 通知 / 一级 | 参会人员 | 处理需要注意的结果或变更 | 未读状态、事件类型、变更前后、发生时间、需要的动作 | 查看详情、接受/拒绝调整、标记已读 | 从底部“通知”进入；跳转 P-09/P-06 |
| P-09 | 我的预约 / 我的内二级 | 参会人员 | 跟踪本人所有预约 | 待审核、已批准、待确认、已拒绝、已取消、已签到等状态与原因 | 打开详情、取消符合条件的预约、打开凭证 | 从“我的”进入；进入 P-10/P-11 |
| P-10 | 预约详情与凭证 / 二级 | 参会人员 | 确认参会资格并出示凭证 | 预约编号、状态、会议关键事实、模拟核验码 | 出示凭证、返回日程/预约 | 只有已批准且未取消的预约显示有效凭证 |
| P-11 | 偏好与演示角色 / 我的内二级 | 全部角色 | 管理语言、时区和演示角色 | 当前语言、时区、角色、模拟边界 | 切换语言/时区/角色 | 切换不改变预约状态；角色只改变可见权限 |
| O-01 | 待审申请队列 / 会务一级 | 会务人员 | 快速定位自己可处理的申请 | 会议范围、申请人、时间、冲突/容量标记、待处理数 | 筛选、打开申请 | 只显示负责会议；进入 O-02 |
| O-02 | 申请审核 / 待办二级 | 会务人员 | 基于事实作出决定 | 会议事实、申请人、容量、冲突、处理说明、同步影响预览 | 批准、拒绝、调整 | 缺少原因或满员不能提交；进入 O-03 |
| O-03 | 审核结果 / 待办状态页 | 会务人员 | 确认结果已同步 | 处理结果、受影响对象、记录入口 | 返回待办、查看记录 | 审核改变预约、日程、通知、凭证/容量和记录 |
| O-04 | 会议管理 / 会务一级 | 会务人员 | 发布负责会议的变更 | 负责会议、当前信息、变更入口 | 打开会议、发起变更 | 只显示负责范围；进入 O-05 |
| O-05 | 会议变更与影响预览 / 二级 | 会务人员 | 安全发布时间/地点/容量/议程变更 | 前后差异、受影响人数、潜在冲突、发布说明 | 发布、取消 | 发布后更新会议、日程、通知和记录 |
| O-06 | 现场核验 / 会务一级 | 会务人员 | 验证到场资格 | 当前会议、模拟核验码输入、最少必要预约信息 | 输入/扫描模拟码、继续核验 | 有效首次码进入 O-07；无效/重复留在本页 |
| O-07 | 核验结果 / 会务状态页 | 会务人员 | 确认签到结果 | 预约编号、会议、签到时间或失败原因 | 继续核验 | 仅首次有效核验写入签到与记录 |
| A-01 | 管理与记录 / 管理二级 | 系统管理员 | 查看权限边界和全量模拟记录 | 角色规则、对象编号、操作者角色、时间、结果 | 查看记录、切换演示数据 | 仅管理查看；不提供代办审核 |

## 4. 跨页面规则

1. 会议详情、日程、通知、我的预约必须展示同一预约的同一状态；界面语言和时区变化不改变预约编号、绝对时刻或状态机。
2. AI 建议只出现在冲突与日程决策点，显示理由与影响；未明确采纳时不改日程。
3. 审核、调整、变更、取消和核验是业务事件，必须同步影响相应对象并写入可见记录。
4. 不同角色使用不同的工作区；演示角色切换归入个人设置，不能绕过权限。
5. 已签到、已拒绝、已取消预约不可再次取消；无效、过期、非本场或重复核验码不可改变签到状态。

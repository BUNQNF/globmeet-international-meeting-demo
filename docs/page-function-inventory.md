# GlobMeet 页面功能清单

**组织方式：** 按页面与任务归属，而非按技术能力罗列。  
**原则：** 一级模块只保留用户常用的任务空间；对象操作、AI、设置、记录和异常处理均在二级或上下文中呈现。

## 1. 一级功能清单

| 端与角色 | 一级模块 | 用户心智模型 | 是否保留 | 原因 |
| --- | --- | --- | --- | --- |
| 参会人员 | 会议 | “我要找一场能参加的会议” | 是 | 是预约旅程的入口，名称直接、常见 |
| 参会人员 | 日程 | “我要看我什么时候去哪里” | 是 | 跨时区参会的核心持续任务 |
| 参会人员 | 通知 | “我需要处理哪些新结果或变更” | 是 | 审核结果和变更必须被看见、可处理 |
| 参会人员 | 我的 | “我要管理自己的预约和偏好” | 是 | 承载预约状态、凭证与个人设置，符合常见移动产品习惯 |
| 会务人员 | 待办 | “我需要处理哪些申请” | 是 | 审核是会务角色最高频且有时效的任务 |
| 会务人员 | 会议 | “我负责哪些会议及其变更” | 是 | 管理和发布变更有清晰对象范围 |
| 会务人员 | 核验 | “我要让到场者通过验证” | 是 | 现场工作有明确时空上下文，应与预约审核分开 |
| 全部角色 | AI 中心 | “我要使用 AI” | 否 | AI 是辅助决策能力，不是用户独立目标 |
| 全部角色 | 操作记录 | “我要看系统日志” | 否 | 对普通参会人低频；在结果页和管理页提供即可 |
| 参会人员 | 签到/核验 | “我要扫描或验票” | 否 | 参会人只需出示凭证；核验由会务人员执行 |
| 全部角色 | 角色切换 | “我要切换演示身份” | 否 | 是 Demo 设置，归入“我的 > 偏好与演示角色” |

## 2. 参会人员端功能清单

| 一级页面 | 二级页面/区域 | 功能 | 优先级 | 触发条件 | 输出/状态影响 |
| --- | --- | --- | --- | --- |
| 会议 | 列表与筛选 | 查看会议、按主题/日期/形式/地区筛选、查看本地时间 | P0 | 打开会议模块 | 仅更新列表与筛选状态 |
| 会议 | 会议详情 | 查看主题、议程、容量、方式、原始时区与本地时间 | P0 | 点击会议卡 | 无写入；进入申请判断 |
| 会议 | 预约确认 | 提交申请、阻止重复申请和满员申请 | P0 | 点击申请 | 创建待审核预约及记录 |
| 会议 | 冲突与建议 | 显示重叠会议/时段，取消、仍提交、查看替代 | P0 | 检测到绝对时间冲突 | 取消不写入；继续提交创建待审；采纳仅更新草稿 |
| 日程 | 时间线/日历 | 查看已批准和待确认预约、切换日期与时区 | P0 | 打开日程模块 | 更新显示偏好，不改变预约 |
| 日程 | AI 建议 | 推荐会议或更合适时段，说明理由，采纳/修改/忽略 | P0 | 用户请求或进入冲突 | 仅明确采纳可影响草稿安排 |
| 通知 | 通知列表 | 查看审核结果、会议变更、调整请求、未读数 | P0 | 产生相关业务事件 | 已读状态可更新；不改变会议事实 |
| 通知 | 变更/调整详情 | 查看前后差异，接受或拒绝会务调整 | P0 | 打开待确认事件 | 接受更新日程；拒绝变为不参加并撤销凭证 |
| 我的 | 我的预约 | 按状态查看、打开预约详情、取消符合条件的预约 | P0 | 打开“我的” | 取消同步名额、日程、凭证、通知和记录 |
| 我的 | 凭证 | 显示有效预约的模拟码和最少必要信息 | P0 | 打开已批准预约 | 仅展示；核验后状态可更新为已签到 |
| 我的 | 偏好 | 切换中文/English、四个演示时区、演示角色 | P0 | 用户主动修改 | 更新会话偏好与可见权限，不改业务状态 |

## 3. 会务与管理端功能清单

| 一级工作区 | 二级页面/区域 | 功能 | 优先级 | 触发条件 | 输出/状态影响 |
| --- | --- | --- | --- | --- |
| 待办 | 申请队列 | 按负责会议和风险查看待审项 | P0 | 打开会务工作区 | 仅更新筛选/选择状态 |
| 待办 | 申请详情 | 查看容量、冲突、申请人和同步影响 | P0 | 打开待审申请 | 无写入，形成处理依据 |
| 待办 | 审核决定 | 批准、拒绝、调整；校验满员与原因 | P0 | 会务人员确认操作 | 更新预约、日程、通知、凭证/容量、记录 |
| 会议 | 负责会议 | 查看会议资料与受影响预约 | P0 | 打开会议工作区 | 无写入 |
| 会议 | 变更发布 | 修改时间、地点、容量或议程，预览影响并发布 | P0 | 会务人员提交变更 | 更新会议、相关日程、通知和记录 |
| 核验 | 核验台 | 输入/扫描模拟码，显示最少必要信息 | P0 | 到场核验 | 首次有效码签到；错误码不改变状态 |
| 核验 | 核验结果 | 显示签到结果或重复/无效原因 | P0 | 核验完成 | 写入或展示既有记录 |
| 管理 | 权限与记录 | 查看角色边界、全量模拟记录与种子数据摘要 | P0 | 管理员进入 | 只读，不允许代办审核 |

## 4. 功能闭环对照

| 业务事件 | 发起页面 | 处理页面 | 参会人可见结果 | 会务/管理员可见结果 |
| --- | --- | --- | --- | --- |
| 预约申请 | 会议详情/预约确认 | 待办申请队列 | 待审核预约与通知 | 待审项与记录 |
| 冲突申请 | 冲突与建议 | 待办申请详情 | 冲突理由、替代建议、提交结果 | 冲突依据和处理结果 |
| 批准/拒绝/调整 | 待办申请详情 | 待办处理结果 | 我的预约、日程、通知、凭证状态 | 队列、容量、处理记录 |
| 会议变更 | 会议变更发布 | 通知/日程 | 变更前后、更新后日程、冲突入口 | 受影响人数、发布记录 |
| 取消预约 | 我的预约详情 | - | 已取消、日程/凭证撤销 | 待审项移除或名额归还、通知、记录 |
| 现场核验 | 凭证 | 核验台 | 已签到状态 | 核验结果与记录 |

# GlobMeet 产品界面覆盖规则

本文件覆盖 `MASTER.md` 中与已确认 T3 视觉不一致的通用建议。优先级为：T1/T2 功能规则 > T3 Figma 与 `docs/visual-spec.md` > 本文件 > `MASTER.md`。

## 视觉令牌

| 角色 | 值 |
| --- | --- |
| 画布 | `#F7F7FB` |
| 内容面 | `#FFFFFF` |
| 软紫表面 | `#EEE9FF` |
| 主文字 | `#1C1B2A` |
| 次文字 | `#78758D` |
| 主操作 | `#493CBA` 至 `#8066E6` 线性渐变 |

| 待审/变更 | `#D98A30` |
| 冲突/拒绝 | `#D94F5E` |

## 组件规则

- 选中筛选、日期与导航使用蓝紫渐变、白字和轻紫阴影。
- 提交、批准等主操作使用靛蓝至紫色渐变，不使用星点纹理。
- 会议卡和日程块保持白色内容面，只可使用 `1.5px` 主题渐变细内描边；不使用渐变填充、玻璃内层或额外投影。
- 内容卡圆角 `16-20px`，按钮与标签可使用胶囊或 `10px` 圆角。
- 中文使用系统 `Noto Sans SC` 回退栈，英文会议名与数字使用 `Inter` 回退栈；不得引入外部字体请求。
- 页面固定为浅色高保真 Demo；不在本轮引入深色主题。

## 交互与响应式

- 动效仅为 `160ms` 的 hover、focus 与按压反馈，并遵守 `prefers-reduced-motion`。
- 手机视口保留底部导航并为其留出滚动空间；会务审核在 `<1024px` 变为单主列。
- 关键操作保持可见焦点、语义标签与至少 `44px` 的触控区域。

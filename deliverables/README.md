# 最终提交物目录

本目录用于放置竞赛最终提交文件。过程文档在仓库根目录的 `docs/` 中，不能替代本目录要求的最终格式文件。

| 目录 | 必须放置的文件 | 提交前检查 |
| --- | --- | --- |
| `01-prd/` | `GlobMeet-PRD.docx` | 可打开；包含场景分析、PRD、流程、版本规划、AI 能力说明与技术说明。 |
| `02-prototype/` | 原型文件（如 `.fig`、`.sketch`、`.xd`）或 `prototype-link.md` | 评审可打开/访问，覆盖主流程和关键反馈状态。 |
| `03-ui/` | 命名完整的 `.png` 高保真页面图 | 至少覆盖参会端会议、日程、通知、个人页以及会务端待办、会议、核验等关键状态。 |
| `04-source-code/` | `globmeet-international-meeting-demo-source.zip` | 压缩包不含 `node_modules`、`dist`、`.git`、环境密钥；解压后可按根目录 README 构建。 |
| `05-ai-evidence/` | AI 设计说明、创新亮点、AI 交互资产/工作记录 | 明确区分真实 AI 与本地模拟规则，不虚构外部模型调用。 |

## 当前状态

请以根目录 `README.md` 的交付清单为准：当前仓库已有源码、源码 ZIP 和可追溯的 Markdown 过程材料；Word PRD、原型源文件、UI PNG 导出、部署地址和 AI 附件仍需在正式提交前生成并放入此处。
